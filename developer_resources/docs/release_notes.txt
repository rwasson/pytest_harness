pytest-harness 0.2.0

This release improves failure handling, warning visibility, nested-path support, and coverage reliability.

Added

* Structured warning capture and dashboard reporting.
* Per-file processing error codes and concise failure reasons.
* Support for nested test and source paths.
* Stronger coverage-equivalence and failure-mode tests.

Changed

* Selected test-file failures are recorded as NOT_PROCESSED instead of stopping the harness.
* Warnings are shown by default and remain nonfatal unless pytest treats them as errors.
* Coverage tables omit empty source files and are restricted to the configured source directory.
* Path, record, and debug handling were simplified.

Fixed

* Coverage-directory ambiguity and nested-path log-name issues.
* Warning-producing files being overlooked.
* Invalid pytest outcomes propagating as harness exceptions.
* Stale summary/dashboard assumptions and outdated test helpers.

Validation

* Full validation suite and linters pass.
* Project coverage is 94%.
* Validation suite has no pytest warnings.
