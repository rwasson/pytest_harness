1. Add an advanced argument for alternative layouts
---------------------------------------------------
`additional_python_paths` : `list[pathlib.Path] | None`

Optional directories added to the import path of each isolated pytest
subprocess.

Use only when tests must import local code outside `tested_code_dir` and its
parent. These paths are used for imports but are not included in coverage.

Default: `None`.

Current behavior
----------------
`tested_code_dir` already handles the normal project layout.

pytest_harness adds `tested_code_dir.parent` to the import path of each isolated
pytest subprocess. Tests can therefore import starting with the directory name
of `tested_code_dir`.

For example:

    tested_code_dir = PROJECT_ROOT / "src" / "sample_package"

allows:

    from sample_package.calculator import add

An additional path argument is not currently needed for the supported
single-package layout. It should be added only if a concrete use case requires
imports from other local directories.


Implementation
--------------
In `record_builder.py`, extend the current pytest subprocess path configuration:

    # Tests import starting with the name of tested_code_dir.
    # This override applies only to this pytest subprocess.
    "-o",
    f"pythonpath={tested_code_dir.parent}",

The final import path should contain:
1. `tested_code_dir.parent`
2. each directory in `additional_python_paths`, in the order supplied

Also required:
- add argument validation
- pass the argument through the complete call pipeline
- determine a reliable representation for paths containing spaces
- document import precedence and duplicate-path behavior

4. Create one run-level failure-details log containing only tracebacks and
processing errors for failed, errored, and not-processed test files.

def _build_not_processed_detail_lines(
    *,
    summary_data: AggregateTestSummary,
    styles: _SummaryStyles,
) -> list[str]:
    if not summary_data.not_processed_test_files:
        return []
    lines = [
        "",
        "",
        *_build_section_heading(
            "Not-processed test file details",
            divider="-" * _DIVIDER_WIDTH,
            styles=styles,
        ),
    ]

    for record in summary_data.not_processed_test_files:
        lines.extend(
            [
                "",
                _styled_field(
                    record.relative_test_file_path,
                    style=styles.file_name,
                ),
            ]
        )

        error_lines = record.file_error_message.splitlines()
        lines.extend(
            "    "
            + _styled_field(
                error_line,
                style=styles.muted,
            )
            for error_line in error_lines
        )

    return lines
