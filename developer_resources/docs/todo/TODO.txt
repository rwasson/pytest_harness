Current behavior
----------------
`tested_code_dir` already handles the normal project layout.

pytest_harness adds `tested_code_dir.parent` to the import path of each isolated
pytest subprocess. Tests can therefore import starting with the directory name
of `tested_code_dir`.

For example:

    tested_code_dir = PROJECT_ROOT / "src" / "sample_package"

allows:

    from sample_package.calculator import add

An additional path argument is not currently needed for the supported
single-package layout. It should be added only if a concrete use case requires
imports from other local directories.
